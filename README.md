# HelloToday 安卓安装包下载

这里只发布 HelloToday 安卓 App 的安装包，不包含源代码。

## 最新版本

到 [Releases](https://github.com/process-shu/hellotoday-download/releases) 下载最新的 `.apk` 文件。

## 安装方法

1. 用安卓手机（Android 8 及以上）打开下载链接，下载 `.apk` 文件。
2. 点开下载好的文件；系统提示“允许安装未知来源应用”时选择允许。
3. 如果 Google Play 保护机制提示“未知应用”，选择“仍然安装”。

> 当前为演示版本，连接测试服务器，数据仅供演示。
